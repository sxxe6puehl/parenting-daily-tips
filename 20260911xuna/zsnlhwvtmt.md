# 芝兰雅香丨“您是医院的宝”——院领导看望百岁老人左启华先生

> 更新时间：2026-09-11 (UTC+8)

5月17日上午，姜辉书记带队到病房看望我国小儿神经专业开创者、北大医院离退休老专家儿科左启华先生，为左老送上101岁的生日祝福。

“您在做什么呢？”

“我在玩微信呀。”

“吃饭好不好？”

“吃饭很香，我不挑食。”

病房里的医生护士们全都笑了。左启华先生慈祥地坐在床上，精神矍铄，思维敏捷，微笑向大家致意，感谢大家的关心。姜书记关切地询问左启华先生的身体状况，认真倾听老专家对医院发展的美好祝愿，代表医院感谢左老在医院建设中的辛勤付出与无私奉献。“您是我们医院的宝，照顾好您是我们的责任！”

院领导和儿科代表将一本左启华先生百年寿辰纪念画册赠送给左老。左老和大家一同回顾了北大医院儿科创建国内第一个儿童神经专业组、开设第一个儿童神经专业门诊的峥嵘岁月，祝福北大医院越来越好，再创辉煌。姜书记还向左老介绍了我院与宁夏共建国家区域医疗中心等项目的近况，请左老一如既往地关注并支持医院的发展。

**左启华：百岁人生的儿科情怀**

左启华教授出生于1921年5月。受父亲的影响，左启华立志从医，于1946年12月毕业后留任北京医学院附属医院（北大医院前身）儿科工作。于1949年10月加入中国共产党。

建国后，受时任北大医院儿科主任、中国儿科奠基人诸福棠院士指引，左启华选择向当时处于空白状态的小儿神经专业发起了深入研究。1958年，左启华教授被公派去苏联留学，专攻小儿神经专业，并获得博士学位。

留学归国后，左启华教授于1961年在北大医院儿科建立了国内第一个小儿神经专业组，并开设了第一个小儿神经专业门诊。最初的小儿神经专业组只有5名医生，随着诊断治疗水平不断提高，专业组的人员和床位逐渐扩大。20世纪60年代，左启华教授培养了我国第一位小儿神经研究生。

1980年，左启华教授受卫生部委托，举办了首届全国小儿神经病学进修班，截止目前，已举办了32期全国小儿神经学习班，为各地培养了一批又一批小儿神经专业人才，带动全国各省陆续开展了小儿神经专业工作。1983年10月，在左启华教授等小儿神经专家的积极筹备下，第一届全国小儿神经学术会议在四川自贡召开，至今已举办到第十八届。1985年，中华医学会儿科分会成立了小儿神经学组，左启华教授任首任学组组长。这标志着经过20多年的努力，小儿神经病学在我国正式成为一个新的医学分支。

数十年来，左启华教授以高瞻远瞩的学术视野和求真务实的治学精神，始终引领和推动着全国小儿神经事业的发展。她于1983年首次将癫痫发作类型的国际分类引入中国，并首次在国内诊断和报道了婴儿痉挛症等小儿神经系统疾病。她最早推动开展了苯丙酮尿症等遗传代谢病的临床筛查工作，最早应用国际定义和诊断标准开展了全国范围的儿童智力低下和先天畸形的流行病学调查。由左启华教授主编的《小儿神经系统疾病》(1981年)是我国第一部在本专业领域的权威巨著，启蒙培养了无数小儿神经专业医生。

**引领发展的北大医院儿科神经专业组**

北大医院儿科神经专业组是国内首创。经过60余年的发展和建设，在专业领域始终保持全国领先水平，是中华医学会儿科学分会神经学组组长首任组长单位、中国医师协会儿科神经疾病专业委员会主任委员首任及现任组长单位。

儿科神经专业与多个国家和地区的高水平儿科神经中心建立了广泛而深入的联系。多位专家在国内外具有重要学术影响，拥有一大批知名学术权威担任国际、国内多个重要学术任职，具有广泛国际影响力。

经过60余年的建设，儿科神经专业逐渐建成了具有自身特色的现代化儿童神经系统疾病综合诊治体系，不仅整体处于国内领先水平，而且在某些亚专业领域已经跻身世界先进行列。在癫痫的临床与电生理诊断、分型、病因诊断与药物治疗，神经遗传病/遗传代谢病的分子诊断、综合治疗，神经肌肉病的电生理、病理及分子诊断和综合管理，神经药理，神经发育与康复等诸多领域开展了系统而深入的临床和应用基础研究，引领国内儿科神经的发展；在国内首次诊断了多种癫痫综合征、神经遗传病等疾病；建立了与国际接轨的癫痫、智力障碍及相关脑发育障碍性疾病、外周神经肌肉病等常见儿科神经系统疾病的诊疗规范；建立了抗癫痫药的浓度监测和群体药代动力学模型并已应用于临床；儿科神经康复门诊提供最全面的儿童发育评价与智力行为评定，以及早期发育干预训练康复与家庭训练指导；已经建立国际水准的多学科团队的儿童癫痫中心。

北大医院儿科神经专业是中国儿科神经病学人才培养的“黄埔军校”，在国内率先开展全国儿科神经病学学习班并持续至今，主持召开多种国内、国际顶级学术会议，出版多部儿科神经高级参考书，培养了大批专业医师和人员，其中不乏各地的专业领军人才。儿科神经专业的全体同道正在以精湛的医学技术、先进的教学理念、严谨的治学态度以及饱满的工作热情而努力奋斗着！
